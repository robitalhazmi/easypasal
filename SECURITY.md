## Reporting a Vulnerability

Security and privacy are taken seriously in EasyPasal. If you discover a security vulnerability or sensitive information exposure, please report it responsibly.

### How to Report

1. **Private Reporting:**
   - Please do **NOT** file a public GitHub issue for sensitive security vulnerabilities.
   - Send an email to the project maintainer at `robitalhazmi@gmail.com` with the subject `[SECURITY] EasyPasal Vulnerability Report`.
   - Alternatively, submit a report via [GitHub Private Vulnerability Reporting](https://github.com/robitalhazmi/easypasal/security/advisories/new) if enabled on the repository.

2. **What to Include:**
   - A clear description of the vulnerability and potential impact.
   - Steps to reproduce or a minimal proof of concept (PoC).
   - Any suggested mitigations or patches if available.

### Response & Handling Timeline

- **Acknowledgment:** Within 48 hours of receipt.
- **Assessment & Patch:** A remediation plan and patch will be prepared and tested against the eval suite.
- **Disclosure:** Once the fix is released, an advisory will be published with credit to the reporter (if desired).
